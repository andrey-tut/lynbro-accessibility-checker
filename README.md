# Lynbro Accessibility Checker

Scan your whole WordPress site against WCAG 2.2 AA, see the element causing each problem and how to fix it, and switch on the fixes that are safe. No overlay. Free.

- WordPress.org: https://wordpress.org/plugins/lynbro-accessibility-checker/ (not yet submitted)
- Documentation: https://plugins.lynbro.dk/lynbro-accessibility-checker
- Support and bug reports: open an issue here, or use the WordPress.org support forum once the plugin is listed.
